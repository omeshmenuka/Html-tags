Main root

<html>
The root element of every HTML page. Everything else goes inside it.
Example:
<html> <head>...</head> <body>...</body> </html>

Document metadata

<head>
Holds information about the page (title, CSS, scripts). Not shown on the page.
Example:
<head> <title>My Page</title> </head>
<title>
Sets the text that appears in the browser tab.
Example:
<title>My Website</title>
<meta>
Gives extra information about the page (charset, description, viewport, etc.).
Example:
<meta charset="UTF-8">
<link>
Links external resources like CSS files or icons.
Example:
<link rel="stylesheet" href="style.css">
<style>
Writes CSS styles directly inside the HTML page.
Example:
<style> body { color: blue; } </style>

Page structure

<body>
Contains all the visible content of the page.
Example:
<body> <h1>Hello</h1> </body>
<header>
Introductory content at the top (logo, title, navigation).
Example:
<header> <h1>My Site</h1> </header>
<nav>
Holds navigation links (menu).
Example:
<nav> <a href="/">Home</a> <a href="/about">About</a> </nav>
<main>
The main content of the page.
Example:
<main> <p>This is the main content.</p> </main>
<section>
A section of content, usually with a heading.
Example:
<section> <h2>About us</h2> <p>We make websites.</p> </section>
<article>
A self-contained piece of content (blog post, news item).
Example:
<article> <h2>My Blog Post</h2> <p>Content here...</p> </article>
<aside>
Side content related to the main content (sidebar).
Example:
<aside> <p>Related links</p> </aside>
<footer>
Footer content (copyright, links, contact).
Example:
<footer> <p>© 2026 My Site</p> </footer>
<h1> – <h6>
Headings. <h1> is the most important, <h6> the least.
Example:
<h1>Main Title</h1> <h2>Subtitle</h2>

Text content

<p>
A paragraph of text.
Example:
<p>This is a paragraph.</p>
<div>
A generic box for grouping content. No special meaning.
Example:
<div class="box"> Some content </div>
<span>
A generic inline container for small pieces of text.
Example:
<p>Hello <span>world</span></p>
<br>
Creates a line break.
Example:
Line 1<br> Line 2
<hr>
A horizontal line (thematic break).
Example:
<p>Section 1</p> <hr> <p>Section 2</p>
<ul>
Unordered (bulleted) list.
Example:
<ul> <li>Apple</li> <li>Banana</li> </ul>
<ol>
Ordered (numbered) list.
Example:
<ol> <li>First</li> <li>Second</li> </ol>
<li>
A list item inside <ul> or <ol>.
Example:
<li>List item</li>
<blockquote>
A longer quotation.
Example:
<blockquote> To be or not to be. </blockquote>
<pre>
Preformatted text (keeps spaces and line breaks).
Example:
<pre> code here </pre>

Inline text

<a>
Creates a hyperlink.
Example:
<a href="https://example.com">Visit site</a>
<strong>
Important text (usually bold).
Example:
<strong>Warning!</strong>
<em>
Emphasized text (usually italic).
Example:
<em>This is important</em>
<code>
Shows a short piece of computer code.
Example:
<code>console.log("Hi")</code>
<mark>
Highlighted / marked text.
Example:
<mark>highlighted</mark>
<small>
Smaller text (side notes, legal text).
Example:
<small>© 2026</small>
<sub>
Subscript text (below the line).
Example:
H<sub>2</sub>O
<sup>
Superscript text (above the line).
Example:
x<sup>2</sup>

Images & media

<img>
Displays an image.
Example:
<img src="photo.jpg" alt="A photo">
<audio>
Embeds an audio player.
Example:
<audio controls src="song.mp3"></audio>
<video>
Embeds a video player.
Example:
<video controls src="movie.mp4"></video>

Embedded content

<iframe>
Embeds another webpage inside the current page.
Example:
<iframe src="https://example.com"></iframe>

Tables

<table>
Creates a table.
Example:
<table> <tr> <th>Name</th> <th>Age</th> </tr> <tr> <td>Anna</td> <td>25</td> </tr> </table>
<tr>
A table row.
Example:
<tr>...</tr>
<th>
A table header cell.
Example:
<th>Name</th>
<td>
A regular table data cell.
Example:
<td>Anna</td>

Forms

<form>
A form for user input.
Example:
<form action="/submit"> ... </form>
<input>
An input field (text, password, checkbox, etc.).
Example:
<input type="text" placeholder="Name">
<label>
A label for a form control.
Example:
<label for="email">Email</label> <input id="email" type="email">
<button>
A clickable button.
Example:
<button type="submit">Send</button>
<textarea>
A multi-line text input box.
Example:
<textarea rows="4" cols="40"></textarea>
<select>
A dropdown list of options.
Example:
<select> <option>Red</option> <option>Blue</option> </select>
<option>
One choice inside a <select>.
Example:
<option value="red">Red</option>

Interactive

<details>
A collapsible section (click to open/close).
Example:
<details> <summary>More info</summary> <p>Hidden text here.</p> </details>
<summary>
The clickable title of a <details> element.
Example:
<summary>Click me</summary>
<dialog>
A dialog box / modal.
Example:
<dialog open> <p>Hello!</p> </dialog>

Scripting

<script>
Adds JavaScript code to the page.
Example:
<script> alert("Hello"); </script>
<canvas>
A drawing area for graphics with JavaScript.
Example:
<canvas id="myCanvas" width="200" height="100"></canvas>
